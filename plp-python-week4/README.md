# Python Week 4 Assignment - Functions & Parameters

* `welcome.py`: Demonstrates defining a custom function with parameters and return values to generate personalized student greetings.
* `toolbox.py`: Implements a multi-purpose utility toolkit containing functions for doubling numbers, evaluating pass scores, and generating flexible greetings with default arguments.

The hardest function to write was `greet` with optional parameters because structuring the format to handle both default and custom greeting arguments cleanly required precise string formatting.
